## 8. 턴 운영 (2~3시간 연속 기준)

**기본 추천:** 연습 3턴은 **5분**, 그 뒤 본 게임은 **3분**.

| 구간 | 시간 | 설정 |
|---|---|---|
| 입장·역할 고르기 | 10분 | 「다음 턴」 누르기 전 (타이머가 아직 안 돌아요) |
| 연습 1~3턴 (미션·예산 요청·분배·생산 연습) | 5분 × 3 = 15분 | 턴 시간 5분 + **공격 잠금** |
| 4턴부터 본 게임 | 3분 × 약 30~55턴 | 턴 시간 **3분** + **「전투 풀기」** 버튼 |
| 쉬는 시간 | 필요하면 | **「일시정지」** → 끝나면 **「다시시작」** |

- 2시간 수업이면 본 게임이 약 30턴, 3시간이면 약 55턴이에요.
- 이유: 한 턴 안에 「요청 → 합참의장 승인 → 생산」 말이 오가야 해서 3분보다 짧으면 어려워요. 처음 3턴은 익숙해질 시간이에요.
- **공격 잠금:** 평소 여섯 나라는 모두 「평화」에서 시작하고, 합참의장이 선전포고를 해야 싸울 수 있어요. 그래도 확실하게 하려고 연습 턴에는 관제실 **「전투 잠금」** 버튼을 눌러 둬요. 4턴이 되면 **「전투 풀기」** 를 눌러요. (같은 일을 SQL로 하는 `ops/combat-off.sql`·`combat-on.sql` 은 비상용이에요.)
- **자동 턴 넘김:** 관제실 화면이 **열려 있으면** 남은 시간이 0:00이 될 때 **저절로 다음 턴**이 돼요 (기본 「자동 넘김: 켜짐」, 버튼으로 끄고 켜요. 끈 상태는 이 컴퓨터가 기억해요). 한 턴에 한 번만 넘어가고, 일시정지 중에는 안 넘어가요. 일시정지를 풀면 **멈춘 시점의 남은 시간부터** 다시 흘러요.
- ⚠ 자동 넘김은 **관제실 탭이 열려 있을 때만** 돼요. 탭을 **맨 앞에 열어 두고** 컴퓨터가 **잠자기·화면 꺼짐**으로 들어가지 않게 해 주세요. 또 **교사 컴퓨터의 시계가 정확해야** 해요 (윈도우 설정 > 시간 및 언어 > 「시간 자동 설정」 켜기). 서버는 혼자 턴을 넘기지 않아요. 자동이 안 되면 「다음 턴」 버튼을 직접 눌러요 (두 번 눌러도 한 번만 넘어가요).
- 턴 시간을 바꾸면 **다음에 「다음 턴」을 누를 때부터** 적용돼요. 관제실 선택칸은 1·1.5·2·3·4·5분이에요. 6~10분은 `ops/turn-seconds.sql`.
- 지금 상태가 궁금하면 `ops/status.sql` (턴·타이머·일시정지·전투·역할 수).

## 9. 재접속 복구 (학생 기기가 꺼지거나 로그인이 날아갔을 때)

역할은 **로그인(익명 계정)이 아니라 학생 번호에 붙어 있어요.** 그래서 어떤 경우든 같은 학생으로 다시 연결하면 **같은 나라·같은 역할·같은 병력**으로 돌아와요 (가짜 DB에서 확인했어요).

1. **새로고침 / 웨일북을 껐다 켬** → 같은 브라우저면 자동으로 돌아와요. 아무것도 안 해도 돼요.
2. **「무역 앱에서 먼저 접속해 주세요」가 나옴** (다른 웨일북, 저장 데이터 삭제 등) → 학생이 「무역 앱으로 가기」 → 자기 자리를 다시 골라요.
   - 「이 자리는 이미 다른 기기로 들어와 있어요. 선생님께 말해 주세요」가 나오면 3번으로.
3. **교사:** 무역 관제실 → **「명단·연결」** 탭 → 그 학생 줄의 **「연결 초기화」** → 학생이 무역 앱에서 자기 자리를 다시 고름 (닉네임은 그대로). 「연결 승인 대기」가 뜨면 승인해요.
4. **기기가 아예 고장 났을 때(결석 처리):** 전쟁 관제실 「역할 지정·결석」 표에서 그 학생 **「결석」** 체크 → 같은 나라의 **합동참모의장이 그 역할의 일을 대신**할 수 있어요 (역할 바에서 그 역할을 눌러요). 학생이 돌아오면 체크를 풀어요.

## 10. 질문봇 (AI 끄기)

- 교사 PC 안에서만 도는 AI 프록시(`npm run war:qna-proxy`)는 **학생 기기에서는 닿지 않아요.** 그래서 **실제 배포본은 AI 호출을 끄고** FAQ 키워드 답(「💬 간단 답변」)만 써요. (`sync-earth-war.mjs` 가 배포 복사본에서만 바꿔요. 원본 코드는 그대로.)
- 수업 중에는 프록시를 켤 필요가 없어요.
