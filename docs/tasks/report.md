## 설계에서 애매해서 내가 정한 것

- 「정찰병이 없으면 첩보가 비어 있음」은 **정찰병이 아예 없는 나라는 첩보가 비어 있다**는 뜻으로 읽었어요. 이미 본 정보는 「○턴에 본 정보」 규칙(떠나도 남음)을 그대로 유지해요 — 두 규칙이 충돌하지 않게
- 스냅샷에 나라 이름·색도 함께 저장 (카드를 그리려면 필요하고, 나라 이름·색은 공개 정보라 노출해도 안전)
- 제출 검사 순서: 열림 검사(NO → REFLECT_CLOSED)를 역할 검사(NO → NO_ROLE)보다 먼저 — 「닫혀 있으면 REFLECT_CLOSED」가 어떤 학생에게도 먼저 적용되게
- 교사 목록의 응답 글도 「○○」로 바꿔서 내려 보냄 — 지시서는 내보내기만 말했지만, 「교사 화면은 그 결과만 쓴다」의 취지로 목록에도 실명이 안 보이게
- 보내기 눌림 조건은 화면에서 검사하고, 서버도 같은 조건으로 다시 검사(둘 다 있어야 안전)
- 문항별 답의 개수(1~4)는 서버에 고정으로 검사 — 질문을 바꾸면 `war-reflect.js`의 QUESTIONS와 이 검사를 같이 바꾸면 됨
