선전포고, 평화 제안·수락, 교사 강제 휴전 RPC와 받은 제안 poll 응답을 구현했습니다. 합동참모의장 외교 탭, 교사 전쟁 현황·강제 휴전 버튼, E4·E8 미션 개방을 적용했습니다. 두 나라 작업은 기존 잠금 순서를 따르며, 강제 휴전 시 관련 나라 사이의 제안만 취소합니다.
