## 점검 2 — 예산 요청 흐름 (고친 것 1건)

- 요청 → 승인: 역할 창고 +5, 합참의장 창고 −5 — 합계가 그대로라 맞아요
- 요청 → 조정(수량 바꿔 승인)·거절: 기록과 창고가 모두 맞아요
- 회수·반납: 부족한 수량은 막고, 0·음수는 아무 일 없어요(창고가 늘지 않아요), 소수는 곧바로 거절돼요
- 결석한 역할이 요청하면 막혀요 — **여기가 구멍이었어요**: 예전에는 결석해도 요청이 만들어졌어요. `war_budget_request`에 결석 확인 한 덩어리를 넣어 막았어요 (functions.sql 몇 줄, 작은 버그)
- 역할 없는 학생·다른 나라 요청 승인·pending 중 두 번째 요청: 전부 잘 막혀요

## 점검 3 — 생산 비용 차감 (고친 것: 없음)

- 병과 10종(창병·투석기·기계화 보병·현대 전차·구축함·전함·전투 헬기·살상용 드론·유도미사일·노동자)을 한 대씩 만들어 봤어요
- 비용 항목을 0으로 만들면 전부 `NOT_ENOUGH`로 막히고, 성공하면 창고가 비용만큼만 줄어요
- 실패한 생산은 창고·도시 기록·유닛 수를 바꾸지 않아요
- 병영 없으면 육군, 항구 없으면 해군 생산이 막혀요. 공군은 수도에서만 만들어요
