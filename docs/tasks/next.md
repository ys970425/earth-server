# 헬피코드 밤샘 점검 지시서 (2026-11-16 밤)

## 헬피 명령 규칙 (반드시 지킴)
1. 시험은 `npm run ...` 한 줄 명령만. `$env:Path` 수정·`cmd /c`·파이프/리디렉션·`node -e` 금지.
2. 시험은 관련 수정을 모두 끝낸 뒤 한 번에 돌린다. 중간에 돌리지 않는다.
3. npm을 못 찾으면 재시도하지 말고 `docs/tasks/report.md`에 적고 코드 작성을 계속한다.
4. git 명령(commit, push, add 등) 금지.
5. `2>&1`, `|` 파이프 금지.

## 목표
**새 기능 금지.** 지금 있는 기능이 잘 도는지만 점검한다. 작은 버그는 고치고, 큰 건 고치지 말고 `docs/tasks/report.md`에 적는다.
(작은 버그 = 한 파일·몇 줄 수정으로 끝나고 규칙·설계를 바꾸지 않는 것. 그 밖에는 모두 큰 건.)

기준 문서: `docs/war-design.md`. 새 병과 표: `docs/tasks/report-units.md`.

## 금지
- `app/trade/` 수정, `supabase/war/config.sql` 손수정(필요하면 `npm run war:config`), `private/` 열기, Supabase 직접 접속.
- 규칙 숫자·병과 표 바꾸기.

## 점검 1 — 1366×768 역할별 화면 흐름
`tests/war/screen.test.mjs`의 방식(puppeteer, `?preview=real`)으로 1366×768에서 역할 다섯 개(합동참모의장·공병·육군·해군·공군)를 각각 연다.
- 글자 잘림·겹침·가로 스크롤·눌러도 반응 없는 버튼이 없는지 본다.
- 위쪽 nav 버튼마다 눌러서 화면이 바뀌는지, 오류(콘솔·pageerror)가 없는지 본다.
- 고친 것·못 고친 것을 역할별로 report.md에 적는다.

## 점검 2 — 예산 요청 흐름 (서버·화면 모두)
요청 → 승인 / 조정 / 거절 → 돌려받기(회수) → 돌려주기(반납)를 역할 조합별로 돌려 본다.
- 승인하면 국고·역할 창고 수량이 정확히 바뀌는가 (합계가 늘거나 줄지 않는가).
- 조정(수량 바꿔 승인)과 거절 뒤 기록과 창고가 맞는가.
- 돌려받기·돌려주기에서 부족한 수량·0·음수·소수·아주 큰 수를 넣으면 막히는가.
- 결석한 역할·역할 없는 학생·남의 나라 학생이 요청하면 막히는가.
- 같은 요청을 두 번 승인·거절하려 하면 막히는가.

## 점검 3 — 생산 비용 차감
`war_produce`로 병과별 1대씩 만든다 (창병·투석기·기계화 보병·현대 전차·구축함·전함·전투 헬기·살상용 드론·유도미사일·노동자).
- 비용 항목 하나씩 0으로 만들면 `NOT_ENOUGH`로 막히는가, 만든 뒤 창고가 비용만큼만 줄었는가.
- 실패한 생산은 창고·도시 생산 기록·유닛 수를 바꾸지 않는가.
- 병영·항구·수도 조건, 특수 부대(나라별 하나)와 필요 자원을 확인한다.

## 점검 4 — 미사일·원거리 경계 사례
`war_attack`·`war_attack_preview`로 거리별로 확인한다. 거리 = 칸 수.
- 창병(사거리 1): 1칸 성공, 2칸 `TOO_FAR`.
- 투석기·전함(사거리 2): 2칸 성공, 3칸 `TOO_FAR`, 1칸에서 반격이 줄어드는지.
- 유도미사일·특수 부대(사거리 3, 상륙 기갑부대는 2): 3칸 성공, 4칸 `TOO_FAR`.
- 유도미사일: 쏘면 사라지는가, 같은 턴 두 번째 사용 불가, 이동력 0이라 움직이지 못하는가.
- 사거리 공격으로는 도시를 점령하지 못하고(`need_melee`) 근접으로만 점령되는가, 공군은 점령 못 하는가.
- 보호막·동맹·평화·전투 시간 아님 상태에서 거절되는가. 미리보기가 실제 결과와 같은가.

## 시험 추가
점검에서 찾은 경계 사례는 `tests/war/night.test.mjs` 새 파일에 모은다 (기존 시험 파일은 고치지 않는다).
끝나면 `package.json`의 `test:war:night`만 추가한다 (`test:all`은 건드리지 않는다).

## 마무리
1. 수정을 모두 끝낸 뒤 `npm run test:all`을 한 번만 돌린다.
2. 보고는 `docs/tasks/report.md`에: 고친 것 / 큰 건(못 고침) / 시험 결과(통과·실패 수). 표 금지, 쉬운 말로.
3. 커밋·푸시하지 않는다.
