## 헬피 명령 규칙 (나중에 시킬 때 지시서 맨 위에 넣어요)
1. 시험은 `npm run ...` 한 줄 명령만. `$env:Path` 수정·`cmd /c`·파이프/리디렉션·`node -e` 금지.
2. 시험은 관련 수정을 모두 끝낸 뒤 한 번에 돌린다. 중간에 돌리지 않는다.
3. npm을 못 찾으면 재시도하지 말고 `docs/tasks/report.md`에 적고 코드 작성을 계속한다.
4. git 명령 금지. `2>&1`, `|` 파이프 금지.

## 1. 전쟁 관제실 자동 「다음 턴」 (수업 중 가장 아쉬운 것)
- 지금: `app/war/js/war-admin.js` 의 타이머는 남은 시간을 **보여 주기만** 해요 (`tick`). 0:00이 돼도 서버는 혼자 턴을 넘기지 않아서, 선생님이 **「다음 턴」을 직접** 눌러야 해요 (`tools/war/sim-25.mjs` 로 확인).
- 설계(Q7 A)는 「관제실 타이머가 0이 되면 자동으로 다음 턴 요청」이에요. 무역 관제실(`app/trade/js/admin.js` 의 `left <= 0 → admin_next_turn`)은 이미 그렇게 해요.
- 할 일: 관제실이 열려 있고 `paused` 가 아닐 때, `turn_end` 가 지나면 `war_next_turn(현재 턴)` 을 **한 번만** 부르기 (`turning` 같은 가드로 중복 방지; 서버는 같은 턴 번호로 두 번 와도 한 번만 처리해요).
- 시험: 시간이 지난 상태에서 한 번만 넘어가는지, 일시정지 중에는 안 넘어가는지.
