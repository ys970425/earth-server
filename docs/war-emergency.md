# 수업 중 비상 대응표 (1쪽 · 각 30초 안에)

**수업 중 열어 둘 탭 4개:** ① 전쟁 관제실 `…/earth-war/app/war/admin.html` ② 무역 관제실 `…/earth-server/trade/admin.html` ③ Supabase **SQL Editor** (「전투 잠금」「전투 풀기」 저장해 둠) ④ `status.supabase.com`
**기억할 것 3개:** 관제실 탭이 열려 있으면 **0:00에 자동으로 다음 턴** (안 되면 **「다음 턴」** 직접) · 막히면 먼저 **「일시정지」** (풀면 멈춘 시간부터 이어져요) · 무역 게임은 전쟁 설치가 건드리지 않아서 **언제든 돌아갈 수 있어요**.

## 1. 학생 기기가 꺼졌어요 / 학생 화면이 안 열려요
1. (10초) 학생에게 `F5` 새로고침. 웨일북을 껐다 켰으면 같은 주소를 다시 열어요 → **같은 브라우저면 자동으로 같은 역할로 돌아와요.**
2. 「무역 앱에서 먼저 접속해 주세요」가 나오면 (10초) **「무역 앱으로 가기」** → 자기 자리 다시 고르기.
3. 「이 자리는 이미 다른 기기로 들어와 있어요」가 나오면 (30초) 무역 관제실 → **명단·연결** → 그 학생 **연결 초기화** → 학생이 다시 고르기. 역할·병력은 그대로예요.
4. 기기가 고장이면 (30초) 전쟁 관제실 **역할 표에서 「결석」 체크** → 같은 나라 **합동참모의장이 대신** 해요 (역할 바에서 그 역할을 눌러요). 돌아오면 체크 해제.

## 2. 한 나라만 턴이 멈춘 것 같아요 (그 나라만 행동이 안 돼요)
화면에 나온 **빨간 안내 글**로 고르세요:
- 「**잠깐 멈춘 시간이에요**」 → 관제실 **「다시시작」** (일시정지가 켜진 거예요, 전체가 멈춘 거예요).
- 「**싸울 수 없는 시간이에요**」 → 연습 턴 잠금이에요. 풀려면 관제실 **「전투 풀기」** 버튼 (안 되면 SQL Editor에서 `combat-on.sql` Run).
- 「**○○이(가) 해요**」 (역할 안내) → 그 역할 학생이 자리에 없거나 다른 역할이에요. 결석 체크(위 1-4) 또는 맞는 역할이 눌러요.
- 「**예산이 부족해요**」 → 정상이에요. 요청을 보내고 합참의장이 승인해요.
- 그 나라 화면만 안 바뀌면 (10초) 그 학생들 `F5`. 그래도 안 되면 **「다음 턴」을 한 번** 눌러 봐요.
- 한 역할 요청이 안 풀려 게임이 서 있으면 합참의장에게 **「요청함 → 승인/거절」** 을 말해 줘요 (병목은 의도된 연습이에요).

## 3. 서버 오류예요 (빨간 글 「문제가 생겼어요」, 여럿이 동시에 안 돼요)
1. (5초) 관제실 **「일시정지」** 를 눌러 학생에게 「잠깐 쉬어요」라고 말해요.
2. (10초) `status.supabase.com` 에서 장애가 있는지, Supabase 대시보드에 **「Paused」** 가 없는지 봐요 (있으면 **Restore project**).
3. (10초) 1분 기다린 뒤 학생들 `F5`. 관제실 화면은 4초마다 알아서 다시 시도해요.
4. 되면 **「다시시작」**. 3분 안에 안 되면 **4번(무역 게임으로 전환)**.
- 설치 SQL 문제로 의심되면 SQL Editor에서 `02-postcheck.sql` Run → ✅ 가 아니면 `problems` 칸을 Claude에게 보내요 (설치 파일은 다시 눌러도 안전해요).

## 4. 전체가 실패했어요 → 무역 게임으로 전환
1. (10초) 학생에게 말해요: **「전쟁 앱을 닫고 무역 앱을 열어요.」**
2. (10초) 주소: `https://ys970425.github.io/earth-server/trade/` — 이미 연결된 기기는 **바로 들어가져요** (전쟁 앱과 같은 로그인).
3. (10초) 나는 전쟁 관제실을 닫고 **무역 관제실 → 진행** 탭으로 수업을 이어가요. 무역 데이터는 전쟁 설치·가져오기가 **바꾸지 않아서** 그대로 있어요 (가짜 DB로 증명).
4. (선택) 수업이 끝나면 무역 관제실 **「백업·복구」 → 「백업 파일 받기」** 로 지금 상태를 저장해요. 전쟁 앱은 다음 시간에 다시 시도해요.
- 칠판에 적을 말: 「전쟁 앱이 잠깐 쉬어요. 무역 앱으로 이어서 해요.」
