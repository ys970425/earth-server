🚨 비상 SQL 카드 (교사용)

언제: 관제실 버튼이 안 눌릴 때만. 어떻게: Supabase 대시보드 → SQL Editor → + New query → 아래 파일 내용 붙여넣기 → Run

📂 파일이 있는 곳: 선생님 PC의 C:\projects\earth-server\dist\war-install\ops\

  • 이 폴더는 설치 준비 때 node tools/war/build-install-sql.mjs가 만들어요 (깃허브에는 없어요).
  • VS Code에서 파일을 열어 내용 전체를 복사해 SQL Editor에 붙여 넣어요.

1️⃣ 언제: 연습 턴을 잠가 둘 때 · 풀 때 (관제실 「전투 잠금」「전투 풀기」 버튼이 안 될 때)

  • combat-off.sql = 전투 잠금 (공격·점령이 「싸울 수 없는 시간이에요」로 막혀요. 이동·생산·예산은 그대로)
  • combat-on.sql = 전투 풀기 (본 게임 시작 전에)
-- combat-off.sql / combat-on.sql 안에 한 줄이 들어 있어요 update war.game set combat_on = false where id = 1; -- 잠금 update war.game set combat_on = true where id = 1; -- 풀기

2️⃣ 언제: 지금 상태가 궁금할 때 (읽기만 해요, 안전해요)

  • status.sql = 턴·타이머·일시정지·전투 잠금·역할 수를 한눈에 봐요.

3️⃣ 언제: 턴 시간을 6~10분으로 바꿀 때 (관제실 선택칸은 1~5분까지)

  • turn-seconds.sql — 파일 안 숫자(초)만 고쳐서 Run. 다음 「다음 턴」부터 적용돼요.
update war.game set turn_seconds = 180 where id = 1; -- 180 = 3분

4️⃣ 비상: 관제실 버튼이 아예 안 눌릴 때 (로그인 없이 SQL Editor에서 돼요)

  • next-turn.sql = 「다음 턴」. 파일 아래쪽 war_next_turn(12)의 숫자를 지금 턴(status.sql의 턴 칸)으로 고친 뒤 Run. 숫자가 다르면 아무 일 없어서 두 번 눌러도 한 번만 넘어가요.
  • pause.sql = 「일시정지」 · resume.sql = 「다시시작」 — 고칠 것 없이 붙여넣고 Run. 여러 번 해도 안전해요. 쉰 시간은 빠지지 않고 남은 시간부터 다시 흘러요.
  • reset-student-link.sql = 학생 기기 「연결 초기화」. admin_reset_binding(7)의 숫자를 학생 번호로 고치고 Run. 그 학생이 다시 이름을 고르면 돼요. 역할·병력·예산은 그대로예요.
  • 결과 칸에 ok = true가 보이면 성공이에요. 빨간 오류가 나오면 다시 누르지 말고 Claude에게 알려 주세요.
