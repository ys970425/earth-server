✅ 웨일북 점검표 — 지구 서버: 전쟁의 시간

수업 전에 웨일북 2대(모둠 1번·2번 기기)로 아래 순서대로 확인해요. 한 항목 1~2분. 막히면 오른쪽 「실패하면 이렇게」를 따라 해요.

무엇을 확인해요기기 ①기기 ②실패하면 이렇게
1역할 입장 — 주소를 열고 내 자리를 고르고, 모둠마다 다른 역할을 고른다. 역할 버튼이 눌린다 「무역 앱에서 먼저 접속해 주세요」 → 무역 앱에서 자리를 다시 고른 뒤 돌아온다 (비상표 1-2). 안 되면 F5
2요청 → 승인 → 생산 — 참모총장이 ✉ 요청을 보내면 합참의장 📬 요청함에서 승인, 참모총장이 🔨 생산 요청함에 안 보이면 F5. 「예산이 부족해요」는 정상 — 요청을 먼저. 대기 요청이 쌓이면 합참의장에게 승인/거절 말해 주기 (비상표 2)
3새로고침 복귀 — F5를 눌러도 같은 역할로 돌아오고 병력·예산이 그대로다 「이 자리는 이미 다른 기기로…」 → 무역 관제실 → 명단·연결 → 그 학생 연결 초기화 (비상표 1-3)
4다음 턴 · 일시정지 · 재개 — 관제실 「다음 턴」이 모든 기기에 1초 안에 반영된다. 「일시정지」→ 학생 화면 멈춤 → 「다시시작」으로 복귀 학생 화면에 「잠깐 멈춘 시간이에요」만 보인다 → 관제실 「다시시작」 (비상표 2). 자동 넘김이 안 되면 「다음 턴」 직접 누르기
51분 턴 자동 넘김 — 턴 시간을 1분으로 두면 0:00이 되면 저절로 다음 턴이 된다 (관제실 화면을 켜 둔다). 관제실 버튼이 「자동 넘김: 켜짐」인지 확인. 시험 뒤에는 「자동 넘김: 꺼짐」으로 잠깐 바꿨다가 원래대로 안 넘어가면 관제실 탭이 뒤에 있는지 확인 → 「다음 턴」 직접 누르기. 시험 뒤 턴 시간을 원래대로
6전투 잠금 · 풀기 — 잠금 상태에서 공격 칸이 안 나오고, 「전투 풀기」 뒤 빨간 칸이 나온다 「싸울 수 없는 시간이에요」가 계속 보이면 관제실 「전투 풀기」 버튼 → 안 되면 SQL Editor에서 combat-on.sql Run (비상표 2)
7물어보기 — 화면의 「물어보기」 버튼을 눌러 추천 질문을 누르면 답이 나온다 버튼이 안 보이면 F5. 답이 안 나오면 학생에게 「선생님께 직접 물어요」로 대체 (faq.json은 수업 자료 확인용)
