📋 교사 진행표 — 지구 서버: 전쟁의 시간

수업 중 열어 둘 것: ① 전쟁 관제실 ② docs/war-emergency.md (비상 대응표) — 막히면 먼저 「일시정지」

🔑 관제실은 무역 관제실에 먼저 로그인한 뒤 같은 브라우저에서 열기. 전쟁 관제실에 「무역 관제실로」 버튼이 보이면 그 버튼은 누르지 않기 — 무역 관제실에서 직접 로그인하고, 주소창에 전쟁 관제실 주소를 다시 입력해서 여세요.

🅐 2시간 버전 (본 게임 약 25턴)
시간교사가 할 말누를 버튼
0–10분“역할을 고르세요. 한 역할은 한 명이에요. 화면 아래 「myoLab」이 보이면 준비 완료!”무역 관제실 「무역 게임에서 가져오기」(초기화 입력)
10–25분“연습 3턴이에요. 미션 탭을 따라 하세요. 예산은 요청 → 승인 순서로. 아직 공격은 잠겨 있어요.”턴 시간 5분 · 공격 잠금(전투 끄기) · 「다음 턴」×3
25–28분“요청 → 승인 → 생산을 한 번 전체에서 해 봤어요. 이제 본 게임! 외교도 시작해요.”턴 시간 3분 · 「전투 풀기」(공격 열기)
28–105분2~3턴마다: “우리 나라 목표를 모둠에서 정해요.” 중간 점검: 요청 대기가 쌓이면 합참의장에게 “요청함 → 승인” 알려 주기관제실을 켜 둠(0:00에 자동 다음 턴) · 필요 시 「일시정지」/「다시시작」
105–112분“이제 종합 점수를 발표해요: 도시 수 + 코인÷10 + 동맹×3 + 완료 미션 수. 관제실 숫자를 보고 나라마다 점수를 읽어 주세요. 정복만이 아니라 경제·외교로도 이길 수 있어요!”전쟁 관제실에서 나라별 도시 수·코인·동맹·미션 확인 · 칠판에 점수 기록
112–120분“돌아보기 버튼이 생겼어요. 모두 답하고 전자칠판에서 우리 나라를 함께 봐요.” 수업 끝나면 「성찰 닫기」도 누르기「성찰 열기」 → 모두 제출 후 「성찰 닫기」 · 「성찰 모아 보기」에서 막대·응답 확인 · 필요 시 「AI에게 넘기기」
🅑 3시간 버전 (본 게임 약 45턴)
시간교사가 할 말누를 버튼
0–10분“역할을 고르세요. 역할 카드를 나눠 줄게요. 내 임무 3줄을 큰 소리로 읽어요.”무역 관제실 「무역 게임에서 가져오기」(초기화 입력)
10–25분“연습 3턴: 이동·요청·승인을 익혀요. 공격은 잠겨 있어요. 모르면 「물어보기」 버튼!”턴 시간 5분 · 공격 잠금 · 「다음 턴」×3
25–30분“연습에서 가장 어려웠던 것 하나를 모둠마다 발표해요.”— (수업용 토론, 게임 일시정지 유지)
30–35분“이제 본 게임. 첩보·외교·시장을 써도 돼요. 도시를 뺏기면 3턴 보호막이 생겨요.”턴 시간 3분 · 「전투 풀기」
35–150분5턴마다 중간 브리핑: “어느 나라가 동맹을 맺었나요?” · 시장 개방 안내: “합참의장은 특산물로 물물교환해요.”관제실 자동 다음 턴 · 필요 시 「일시정지」 · 장애면 docs/war-emergency.md 4번(무역 전환)
150–157분“이제 종합 점수를 발표해요: 도시 수 + 코인÷10 + 동맹×3 + 완료 미션 수. 나라마다 점수를 읽어 주세요. 정복만이 아니라 경제·외교로도 이길 수 있어요!”전쟁 관제실에서 나라별 도시 수·코인·동맹·미션 확인 · 칠판에 점수 기록
157–165분“마지막 15분의 성찰! 돌아보기에 답해요. 친구 이름은 쓰지 않아요.” 수업 끝나면 「성찰 닫기」도 누르기「성찰 열기」 → 모두 제출 후 「성찰 닫기」 · 「성찰 모아 보기」로 막대·응답 확인
165–180분“전자칠판의 행복도·군사력·코인을 보고, 오늘 제일 잘한 선택은 무엇이었나요?”「AI에게 넘기기」(복사·.md) · 무역 관제실 「백업 파일 받기」(선택)

🚨 비상: 학생 화면이 안 열리면 F5 → 안 되면 무역 관제실 「연결 초기화」 · 한 나라만 멈추면 빨간 안내 글 확인(잠깐 멈춘 시간=일시정지, 싸울 수 없는 시간=전투 풀기) · 전체 실패면 전쟁 앱 닫고 무역 앱으로 전환 — 자세한 것은 docs/war-emergency.md
